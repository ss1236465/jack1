# Three.js 手势交互粒子网页

当前分支版本：第二版。

蓝青色全息粒子、三维能量球和爱心，通过摄像头追踪手势控制扩散、缩放与旋转。

## 本地运行

安装 Node.js 后，在此目录打开终端并运行：

```sh
node server.cjs
```

浏览器打开 http://localhost:8001/。无需安装 npm 依赖。

也可使用 Python 启动：

```sh
python -m http.server 8001
```

网页需要通过本地 HTTP 服务打开。朋友远程使用摄像头时，需要通过 HTTPS 访问。

## 交互

- 点击“开启手势”并允许摄像头访问。模型加载完成后，界面自动进入纯粒子模式。
- 张手扩散，握拢汇聚；双手距离控制缩放，手的位置及倾斜控制旋转。
- 比数字 1 显示粒子“1”，比数字 2 显示“2”。
- 连续比出 1 → 2 → 5 显示“i love you”；单独比 5 不触发表白文字。
- 每个数字手势保持约 0.3 秒，每一步间隔不超过 5 秒；表白文字显示 6 秒。
- 按 Esc、双击或双点画面恢复控件；再次双击或双点隐藏控件。
- 鼠标移动旋转，按住画布扩散，滚轮缩放。
- 控件支持切换能量球和爱心、调整颜色和全屏显示。

## 模型加载

MediaPipe Hands 版本为 `0.4.1675469240`，相关文件位于 `vendor/hands/`。

模型下载显示进度，优先使用站内资源，并在传输较慢时尝试固定版本的 jsDelivr、unpkg 资源。文件通过大小和 SHA-256 校验后使用，成功下载会尝试缓存在浏览器中。摄像头画面在本机处理。

## 部署

将本目录的网页文件及整个 `vendor/` 目录上传到静态网站目录，首页设为 `index.html`。

- 必须保留 `hand-tracker.js`、`gestures.js` 和模型资源的相对目录。
- `.wasm` 文件使用 `application/wasm` 类型，`.js` 使用 JavaScript 类型。
- `.gz` 文件为压缩模型资源，由网页加载器解压。
- Three.js 目前从 jsDelivr 加载，首次访问需要网络连接。
- `server.cjs` 是本地预览服务，默认仅监听本机。
