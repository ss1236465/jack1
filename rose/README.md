# 代码玫瑰

本目录保存代码玫瑰原版、第二版与第三版。共享的 Three.js 脚本在 `vendor/`，背景音乐在 `media/`。

| 版本 | 线上入口 | 仓库文件 |
| --- | --- | --- |
| 原版 | http://47.117.82.118/rose/ | `index.html` |
| 第二版 | http://47.117.82.118/rose/v2/ | `v2/index.html` |
| 第三版 | http://47.117.82.118/rose/v3/ | `v3/index.html` |

第二版保留铁盒开场、音乐律动、粒子爱心、星光轨迹、情书与图片保存。

## 第三版：铁盒里的回忆

点击“翻开回忆”后，当前《半岛铁盒》MP3 与六幕场景一起开始。旧书、铁盒、暖色玫瑰、雨幕、日记和花瓣归盒组成一条回忆线。

| 首次进入 | 章节 | 画面 |
| --- | --- | --- |
| 0:00 | 翻开旧书 | 昏黄灯光下的书页和桌面，镜头缓缓靠近 |
| 0:35.55 | 发现旧铁盒 | 锈迹、浮尘和铁盒缝隙中的微光 |
| 0:47.09 | 温暖的回忆 | 盒盖开启，粉色与琥珀色玫瑰生长 |
| 1:15.05 | 雨中的离别 | 雨痕、冷色光和随风散去的花瓣 |
| 1:59.93 | 记忆逐渐模糊 | 旧日记和化成光点的字迹 |
| 4:59.40 | 收起这一刻 | 花瓣归盒，盒盖合拢，留一道光 |

后续主歌与副歌会再现暖色、雨幕和记忆段落，并加深冷暖与消散变化。时间点参考当前约 5 分 19 秒的音频与 LRC 标记，是场景转折的近似定位。页面文案为原创短句，不展示完整歌词或个人姓名。

- 故事时间直接取自 `audio.currentTime`。暂停、进度拖动、章节跳转和回放都会对应到同一幕；场景不会因为等待播放而提前演完。
- 歌曲播放到尾声后停留在收盒画面，不自动循环。点击“再听一次”可重新开始。
- Web Audio Analyser 读取音量与低频，只控制花瓣呼吸、光晕和细小粒子的强弱。
- 点击花朵或爱心按钮，可让花瓣短暂聚成爱心；暖色段落也有短暂的爱心时刻。
- 拖动留下的轨迹会随故事由星光转为浮尘，同时可以转动视角。
- 长按玫瑰或点击日记按钮，翻阅和编辑自己的话；只保存于当前浏览器的 localStorage。
- 保存按钮可导出当前画面为 PNG。播放按钮、进度条和章节入口方便重看指定片段。

音频继续使用原版相同的 `media/bandao-tiehe.mp3`，没有重复存储或替换曲目。

场景代码分别为 `v3/story-timeline.js`（纯时间线）、`v3/story-scene.js`（桌面、书、盒子与天气）、`v3/diary.js`（日记交互）及 `v3/app.js`（玫瑰、播放和场景整合）。

## 本地预览

在仓库根目录运行：

```sh
node server.cjs
```

打开 `http://localhost:8001/rose/v3/`。第二版为 `http://localhost:8001/rose/v2/`，原版为 `http://localhost:8001/rose/`。

页面需要 WebGL。音乐律动在浏览器支持 Web Audio 时启用；歌曲播放需要一次点击。

## 验证

```sh
node rose/tests/story-timeline.cjs
node rose/tests/story-interactions.cjs
node rose/tests/story-routes.cjs http://localhost:8001
node rose/tests/interactions.cjs
node rose/tests/routes.cjs http://localhost:8001
```

时间线检查覆盖段落边界、前后跳转和尾声。交互检查在模拟 DOM、音频与渲染接口中运行实际脚本，覆盖播放、时间同步、长按与拖动、日记持久化、爱心恢复、重看重置和图片导出。HTTP 检查验证全部场景资源、带查询参数的缓存地址、原版与音频校验值，以及 MP3 分段请求。实际 WebGL 画面需另用浏览器预览。

## 部署

将本目录同步到服务器：

```text
/opt/1panel/apps/openresty/openresty/www/sites/game/index/rose/
```

`v2/` 与 `v3/` 使用 `../vendor/` 与 `../media/`，资源由三个版本共享。部署第三版只需新增 `v3/`。版本二的页面与资源校验值保持原样。
